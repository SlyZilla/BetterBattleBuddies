Better Battle Buddies

General AI improvements for Arma Reforger, usable independently of AC: Actual.
AI scan their surroundings, recover weapon readiness, and use existing engagement,
suppression, vehicle-helper and optional medical improvements. No commander game
mode is included. ACE features require ACE; ACE is not a hard dependency.

Development extraction: Workshop release and installed multiplayer acceptance pending.
